# Workflow: /process-inbox

Follow this workflow to process notes in `notes/inbox/`.

## Steps
1. Inspect `notes/inbox/ideas.md` or any new files in `notes/inbox/`.
2. Extract user ideas, architectural notes, and feature requests.
3. Categorize items into `ROADMAP.md` (Wishlist or Planned).
4. Move processed notes to `notes/processed/`.
